## 새 기능

### 대시보드 overview 자동 생성

새 달에 진입할 때 홈 화면의 실자산/은퇴자금/전월대비 변동 데이터가 자동으로 생성됨.

- `financialStatus` + `monthlySummaries` 기반으로 `overview` 문서 자동 계산 및 저장
- 자산 금액 변경 시 overview도 함께 갱신
- 자산 데이터가 없는 달에는 "이번 달 자산을 업데이트해주세요" 유도 버튼 표시

커밋: 174f5b1

### 계좌 전체 필드 수정 기능

기존 금액만 수정 가능했던 계좌 편집 화면에서 모든 필드를 수정할 수 있도록 확장.

- 기본 모드: 금액만 빠르게 수정 (기존과 동일)
- "상세 수정" 버튼 클릭 시: 분류, 소유자, 계좌 유형, 상세 유형, 계좌명, 금융기관 모두 편집 가능

커밋: e69c119

### OptionPicker 바텀시트 컴포넌트

계좌 유형, 상세 유형, 금융기관 등을 기존 데이터에서 추출하여 바텀시트 모달로 선택.

- 기존 계좌 데이터에서 옵션 동적 추출
- "직접 입력" 모드 지원 (모달 내 TextInput 전환)
- 계좌 추가/수정 화면 모두 적용

커밋: e69c119

### 홈 실자산 카드 → 재무상태 바로가기

홈 화면의 실자산 히어로 카드를 탭하면 재무상태 화면으로 바로 이동.

커밋: e69c119
